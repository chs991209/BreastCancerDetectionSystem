# 유방암 검출 시스템 (BCS-DBT) — 전체 진행 기록

**작성일:** 2026-07-02 · **갱신:** 2026-09-07
**주 목적:** **의료 AI 시스템의 재현성(reproducibility).** 유방암 DBT→2D 전이 파이프라인은 그 *수단*.
**과제:** **병변 존재(lesion presence)** 검출 — abnormal = benign + malignant, normal = no-lesion.
결합 3D DBT(BCS-DBT + DBT-2026) **파인튜닝** → 2D 유방촬영 **전이학습**.
**기반 논문:**
- *"Detection of breast cancer in digital breast tomosynthesis with vision transformers"* (Sci Rep, 2024) — Swin-B @384 + 슬라이스 이동평균(W=8) 집계. **우리 DBT 단계의 직접 선행연구.**
- *"SIFT-DBT"* (2024) — 자기지도(MoCo v2) + 패치 MIL.

## 0. 현재 상태 요약 (2026-09) ✅

**용어:** 파인튜닝 = 3D DBT 단계 / 전이학습 = 2D 단계. (아래 1~n장 상당수는 초기 단일-BCS-DBT 시기의 이력임.)

### Stage 1 — DBT 파인튜닝 (결합, held-out TEST AUROC)
| 체크포인트 | 초기화 | VAL | TEST |
|---|---|---|---|
| combined_25d_swinb… | ImageNet | 0.951 | **0.929** |
| combined_25d_swinbscratch… | scratch | 0.894 | 0.851 |

- 결합 = BCS-DBT + DBT-2026, 병변존재 라벨(actionable 제외, Group B는 polygon 유무로 purely-normal 분리).
- 라벨 = **scan(볼륨) 단위** 1개. per-slice Swin-B + **MIL max(over Z)** + focal loss. (saliency/WSOL·Dice는 초기 코드 잔재, 결합 파이프라인에서 미사용.)
- 아키텍처: **2D Swin-B를 슬라이스별로 적용**(3D Swin 아님) + 2.5D(k=3 인접슬라이스 채널). 손실 = focal only.

### Stage 2 — 2D 전이학습 (3조건, 5시드, held-out TEST)
- **m0** = ImageNet-only · **m1** = ImageNet→DBT(가중치전이 + full-FT + LLRD) · **mscratch** = scratch→DBT.
- 데이터셋(환자단위 split, 무누수): 병변 = EMBED/EMBED-natural(USA), MIAS(UK), CDD-CESM(Egypt); 악성 = CMMD(China), RSNA(USA, ~2%), CBIS-DDSM(USA). arm = natural / balanced.
- **제외(부적격):** INbreast(환자ID 없음→누수), BUSI(초음파), VinDr(생검 라벨 없음).

**핵심 결과(TEST AUROC, mean, 대표값):**
| 데이터셋 | m0 | m1 | mscratch |
|---|---|---|---|
| EMBED-nat | 0.712 | **0.745** | 0.539 |
| MIAS(nat) | 0.504 | **0.707** | 0.504 |
| CDD-CESM(nat) | 0.717 | **0.812** | 0.549 |
| CMMD(nat) | 0.686 | **0.783** | 0.546 |
| CBIS(nat) | 0.658 | **0.756** | 0.565 |
| RSNA(bal) | 0.550 | **0.688** | 0.496 |

- 전 데이터셋 **m1 > m0 > mscratch** 일관. m1은 **시드 분산도 최소**(재현성 결과). mscratch(DBT-only, ImageNet 없음)는 2D 전이에서 거의 chance → **ImageNet 기반이 전이 가능 특징의 핵심**, DBT는 그 위에 얹는 추가 학습.
- 밸런싱(natural vs balanced)은 결과를 ±0.02~0.04만 이동 → 결론 불변.

### 추가 소거실험
- **LLRD**: plain(기하 0.75) 0.778 > imbalanced(fine-stage) 0.765 > flat 0.775 (EMBED). 모든 전이 m1/mscratch에 LLRD 기본 적용.
- **cosine head + weighted-CE (m1cos)**: m1(MLP+focal) 대비 데이터셋별 혼재(±0.02 내외), CDD-CESM/MIAS-natural에서 소폭↑·저분산, CBIS/MIAS-bal에서 ↓. 명확한 우열 없음.

## 4. 모델 (`model.py` — `DimensionAgnostic3DSwin`)

- **백본:** Swin-B (`swin_base_patch4_window12_384`), 흑백 `in_chans=1`, ImageNet 사전학습(또는 `ssl_weights=`로 SSL 백본 로드).
- **분류 헤드:** `Linear(C→C/2)→GELU→Dropout(0.3)→Linear(C/2→1)`.
- **WSOL saliency:** `forward_features` → permute → `1×1 Conv` → 384 업샘플 → sigmoid → 슬라이스별 `[B,Z,384,384]`.
- **forward:** `[B,Z]` 평탄화 → 유효 슬라이스만 → chunk(32) 백본 통과(학습 시 gradient checkpointing) → `logits [B,Z]` + `saliency [B,Z,384,384]` 반환(패딩 로짓=-inf).
- **동결 정책:** `freeze_backbone=True`(Phase A) → patch_embed+stage0-1+헤드만 학습(~2.65M); `False`(Ceiling-Break) → 전체 개방(87.40M) + LLRD.
- **A6000 최적화:** bf16 autocast, TF32, cuDNN benchmark, 패딩 슬라이스 연산 제거.

## 5. 클래스 불균형 대응 — 변천사

| 단계 | 방법 | 결과 |
|------|------|------|
| v1 | 단순 `shuffle`(균등) | 배치 ~98%가 전부 음성 |
| v2 | `WeightedRandomSampler` 오버샘플(≈1:1) | 균형 but 76개 양성 반복 |
| v3 | `UndersampleNormalSampler`(Normal→12%) + `pos_weight` | 양성율 0.40%→2.45% |
| **v4(최종)** | **`BalancedBatchSampler`**(배치당 고정 비율) + 온더플라이 증강 | 배치별 양성 보장 |

- 최종 학습: `BalancedBatchSampler` **`pos_fraction=0.25`(1:3)** + **Focal Loss(α=0.75, γ=2)** + 경증강(hflip + 밝기/대비).
- 증강은 **미세석회화 보존**을 위해 블러 제외.
- `data_preprocessing.py` 에 세 샘플러 모두 구현.

## 6. Phase A — 지도학습 MIL + WSOL ✅ (AUROC 0.732)

논문 계획 + 바운딩박스 국소화(Gemini "V2.1" 지시).

- **분류:** 슬라이스 로짓 **MIL max-pool** → **Focal Loss**.
- **국소화(WSOL):** 슬라이스 saliency와 GT 박스 마스크의 **게이팅 Dice Loss**(박스 있는 슬라이스에만; 박스가 면적의 ~2%뿐 → BCE는 saliency→0 붕괴하므로 Dice 사용).
- **추론:** scan 확률 = `max(이동평균₈(sigmoid(슬라이스 확률)))` (논문 방식); 박스 = MIL-max 슬라이스 saliency 임계화 → `cv2.boundingRect`(384 패딩 좌표계).
- **손실:** `L = FocalCls + 0.1·Dice`, 조기종료(patience 4).

### 회귀(regression)와 수정 — 중요 디버깅 기록
- **1차 시도(1:7 + focal α=0.25 + λ=1.0):** AUROC **0.53 / F1 0** 으로 전-음성 붕괴.
  원인 (1) λ=1.0이라 Dice(~0.9)가 focal_cls(~0.1)를 압도, (2) α=0.25가 희소 양성을 **down-weight**, (3) 1:7이 양성을 더 희석.
- **수정(1:3 + α=0.75 + λ=0.1):** → **AUROC 0.732 회복**, 안정화(0.69→0.715→0.72→0.732).
- F1은 낮음(작동점/캘리브레이션 이슈) — 단, 합의된 주지표는 AUROC.

### 논문 정합성
- ✅ 아키텍처(Swin-B@384) + 슬라이스→scan 이동평균(W=8) 집계 = 논문 일치.
- 의도적 상이점: 양성=암 단독(논문=biopsied), balanced-batch(논문=weighted loss), `in_chans=1`(논문=3채널 복제), 심층 stage 동결(논문=전체 학습).

## 7. Phase B — SIFT-DBT 자기지도 사전학습 ✅ (수렴 성공)

**목표:** 라벨 없는 ~19k 볼륨으로 백본이 DBT 도메인을 학습 → 76개 양성 천장 완화.

- **`pretrain_ssl.py`** — 캐시 슬라이스 위 **MoCo v2** 대조학습(라벨 불필요).
  - **양성쌍(DBT 특화):** 교차뷰(같은 study 다른 view, p=0.25) 또는 인접 슬라이스(±9).
  - Swin-B 인코더 + 2-layer projection(128); momentum key encoder; 큐 K=4096, m=0.99, T=0.2.
  - 경증강(블러 제외 → 미세석회화 보존), AdamW+cosine, bf16, gradient checkpointing.
  - **백본만 저장** → `checkpoints/ssl_swinb_backbone.pth` (키 327개가 파인튜닝 모델과 동일함을 검증, strict 로드 OK).

### SSL 실패 → 수정 — 중요 디버깅 기록
- **1차 SSL(bs256):** top1이 ~0.00-0.02에 정체, loss ~8.3(=ln(K+1), 무작위 수준), 3에폭간 **학습 안 됨**. VRAM 46.5GB 근접.
  원인: 백본 **무작위 초기화**(pretrained=False) + m=0.999(스텝 적어 key encoder 거의 안 움직임) + 어려운 교차뷰 50% + 스텝 부족.
- **수정:** **ImageNet 웜스타트**, m=0.99, cross_view_p 0.5→0.25, `repeat=4`(스텝↑), bs 256→192(VRAM).
- **결과:** top1 0.02→**0.883**(25에폭), loss→3.81. 깨끗한 수렴, 붕괴 없음.

| epoch | 10 | 15 | 20 | 25 |
|-------|----|----|----|----|
| loss  | 3.99 | 3.88 | 3.83 | **3.81** |
| top1  | 0.858 | 0.872 | 0.880 | **0.883** |

## 8. Ceiling-Break Test — 천장 돌파 시도 ❌ (실패)

SSL 백본 + **전체 개방** + **LLRD**(head 1e-4 / stage0-1 1e-5 / stage2-3 1e-6), 나머지(1:3, Focal α=0.75, Dice λ=0.1)는 Phase A와 동일.

- 실행: SSL 백본 로드 ✓, LLRD 분할(0.53M+2.12M+84.75M=87.40M) 검증 ✓, VRAM 24GB ✓.
- **결과: 조기종료 5에폭, 최고 AUROC 0.7015.** 그러나 **1에폭 정점 후 하락**(0.70→0.66→0.64→0.61→0.62)하며 val loss 상승(0.03→0.12) = **명백한 과적합**.

| 모델 | Val AUROC |
|------|-----------|
| V2.0 분류전용 | **0.749** (최고) |
| Phase A (ImageNet+동결+WSOL) | 0.732 |
| Ceiling-Break (SSL+개방+LLRD) | **0.7015** ❌ (과적합) |

- **해석:** 87M 파라미터를 76개 양성에 개방 → LLRD 저학습률·조기종료로도 과적합 억제 실패.
  또한 SSL 1에폭(0.702) ≈ ImageNet Phase A 1에폭(0.695) → **SSL 초기화가 뚜렷한 이점을 주지 못함**.
- **추정:** MoCo 인스턴스 판별 특징(top1 0.88)이 *악성 판별*로 전이되지 않았을 가능성. (슬라이스 자기매칭 ≠ 미세 암 검출)
- **미해결(주의):** 이 실험은 초기화(SSL)와 동결정책(개방)을 **동시에** 바꿔, 승패를 SSL 단독에 귀속 불가.
  → **깨끗한 비교(SSL+동결)** 필요(다음 단계).

   - SSL+동결 ≤ 0.732 → SSL(MoCo)가 악성 판별로 전이 안 됨 → **천장은 데이터(76개)** 문제, 초기화로 해결 불가.
2. 천장이 데이터 한계로 확인되면 **양성 신호 확대**가 정답:
   - 양성 정의를 **biopsied(Benign+Cancer=200)** 로 (단, 과제가 병변검출로 바뀜),
   - **EMBED** 2D 사전학습(악성 ~1,585개; 단 2D·이미지 미다운로드),
   - **패치 단위(원해상도) MIL**(SIFT-DBT식; 384 다운스케일로 소병변 손실 방지).
3. 작동점/F1 개선: 임계값 캘리브레이션(주지표 AUROC는 유지).

## 12. 교훈 정리

- **exfat 로그 금지:** 대량 stdout을 exfat SSD 로그로 쓰면 크래시 → nvme 로그.
- **bf16(≠fp16):** Ampere에서 `-1e9` 마스킹 오버플로우 회피, GradScaler 불필요.
- **불균형은 하이퍼파라미터에 민감:** 균형 샘플링은 과적합, 과한 언더샘플+잘못된 focal은 붕괴. 근본 해법은 *양성 신호 증대*이지 샘플러 튜닝이 아님.
- **소수 스텝 in-domain MoCo는 ImageNet 웜스타트 + 낮은 momentum 필수.**
- **76개 양성 천장은 구조적:** 지도 ~0.73-0.75가 한계이며, 초기화 트릭(SSL)+전체개방은 오히려 과적합으로 악화됨.
- **실험은 한 번에 한 변수만:** SSL+개방을 동시 변경해 원인 귀속이 어려워짐 → 통제된 비교 필요.
