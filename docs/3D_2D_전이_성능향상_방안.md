# 3D → 2D 전이학습 성능 향상 방안

**작성일 2026-08-25 · 대상: DBT(3D) → 2D 유방촬영술 전이학습**
논문 주제(의료 AI 시스템의 재현성)에 부합하도록, **재현 가능·인용 가능·소거실험(ablation) 검증 가능**한 방안만 정리.

---

## 0. 현재 구조와 핵심 병목

- **현재 전이(방향 B):** 결합 DBT 2.5D Swin-B 체크포인트를 동일 구조 2D Swin에 strict 로드 → focal 손실로 미세조정. full fine-tune이 최고.
- **현재 EMBED 기준선:** full-FT **0.775** (LLRD 적용 시 0.778로 상승 중, 실행 중).

### 핵심 병목 — 채널 복제 문제
`transfer_learning/mammo2d_base.py`의 148번째 줄에서 **2D 흑백 이미지를 3채널에 '동일하게' 복제**한다.

```
vol = t.unsqueeze(0).unsqueeze(0).repeat(k, 1, 1, 1)   # [k,1,H,W] — 3채널 전부 동일
```

그런데 DBT stem(`patch_embed`)은 **인접 슬라이스 간의 '차이'(inter-slice texture gradient)** 를 읽도록 학습되었다.
2D에서는 3채널이 모두 같아 **채널 간 변화량이 0** → 전이된 stem 용량이 낭비된다. → **수정 가능한 지점.**

## 1. 방안 비교표

| 방안 | 내용 | 비용 | 기대 효과 | 재현성 부합 |
|---|---|---|---|---|
| **A. LP-FT** (선형 프로빙 후 미세조정) | backbone 동결 후 head만 먼저 학습(2ep) → 이후 전체 미세조정 | 낮음 | full-FT는 사전학습 특징을 왜곡(Kumar 2022). LP-FT는 DBT 특징을 보존 → 전이 향상. **인용 가능** | 결정적, 인용 가능 |
| **B. 2.5D 채널 재매핑** | 3× 흑백 복제 대신 `[원본, CLAHE, 엣지(DoG)]` 입력 | 낮음 | 채널 민감 stem에 '진짜 신호' 공급 → 낭비된 용량 활용 | 결정적(고정 변환) |
| **C. 합성 2D 브리지 (C-view)** | DBT 볼륨을 2D 투영(MIP/평균=임상 C-view)으로 붕괴 → DBT 라벨로 head 선학습 → 이후 실제 2D 전이 | 높음 | 3D→2D 모달리티 격차를 **기존 라벨로** 메움. 잠재 이득 최대 | 기존 라벨 재사용, 인용 가능 |
| **D. EMA/SWA** | 결정적 가중치 평균 | 매우 낮음 | 일반화 + 재현성 소폭 향상 | 결정적, 재현성 직접 기여 |

> 모든 방안은 EMBED(가장 깨끗한 세트)에서 기준선(full-FT 0.775) 대비 소거실험으로 검증 가능.

## 2. 방안별 상세

### A. LP-FT (Linear-Probe then Fine-Tune)
- **원리:** 사전학습 특징이 좋을 때, 처음부터 전체 미세조정하면 무작위 초기화된 head의 큰 그래디언트가 backbone 특징을 **왜곡**시킨다. head를 먼저 수렴시킨 뒤(선형 프로빙) 전체를 풀면 왜곡이 줄어든다.
- **구현:** `run_transfer`에 2단계 스케줄 추가 — Stage A(backbone 동결, head 2ep) → Stage B(전체 해제 + LLRD).
- **인용:** Kumar et al., *"Fine-Tuning can Distort Pretrained Features and Underperform Out-of-Distribution"*, ICLR 2022.
- **위험:** 거의 없음. 기존 LLRD와 결합 가능.

### B. 2.5D 채널 재매핑
- **원리:** DBT stem이 학습한 '채널 간 차이 감지' 능력을 2D에서도 쓰려면, 3채널에 **의미 있는 다중 표현**을 넣어야 한다.
- **후보 매핑:** `ch0=원본`, `ch1=CLAHE(대비 향상)`, `ch2=DoG/엣지(고주파=미세 병변 텍스처)`.
- **구현:** `mammo2d_base.py`의 `__getitem__` 채널 생성부만 교체(플래그로 on/off).
- **재현성 논점:** '병변의 미세한 차이' 가설(불균형 LLRD와 동일 맥락)과 직접 연결 — 고주파 채널이 미세 병변 신호를 강조.
- **위험:** 낮음. 다만 DBT 학습 시의 채널 통계와 완전 일치하진 않음(소거실험으로 확인).

### C. 합성 2D 브리지 (C-view / MIP)
- **원리:** 임상에서 DBT로부터 합성 2D(C-view)를 만드는 것처럼, DBT 볼륨을 **최대/평균 강도 투영(MIP/mean)** 으로 2D화한다. 이 합성 2D는 **DBT 라벨을 그대로 상속** → 대규모 2D-유사 라벨 데이터.
- **파이프라인:** `DBT vol [Z,384,384] → MIP → 합성 2D` → head 선학습(DBT 라벨) → 실제 2D 전이.
- **장점:** 3D→2D 격차를 **새 데이터 없이** 메움. 논문 novelty 최대.
- **비용:** 합성 2D 캐시 생성 + 중간 학습 단계 추가 → 작업량 최대.

### D. EMA/SWA 가중치 평균
- **원리:** 학습 후반 가중치를 지수이동평균(EMA) 또는 SWA로 평균 → 평탄한 최소값 → 일반화·재현성 향상.
- **구현:** `run_transfer`에 EMA 모델 추가, 검증은 EMA 가중치로.
- **역할:** 단독보다 **최종 우승 방안에 얹는 마감 옵션**.

## 3. 권장 실행 순서

1. **1단계 (즉시, 저비용):** A(LP-FT) + B(채널 재매핑) — 둘 다 EMBED에서 기준선 0.775 대비 소거실험. 빠르고 위험 낮음.
2. **2단계 (후속, 고이득):** C(합성 2D 브리지) 구축.
3. **마감:** 우승 조합에 D(EMA) 적용.

### 소거실험 설계(EMBED, seed=42, plain ratio 고정 → 재현성)
| 실험 | 설정 | 비교 대상 |
|---|---|---|
| 기준선 | full-FT | 0.775 |
| +LLRD | plain/imbalanced | 0.778(실행 중) |
| +A | LP-FT | vs 기준선 |
| +B | 채널 재매핑 | vs 기준선 |
| +A+B | 결합 | vs 각 단독 |
| +C | 합성 2D 브리지 | vs 최선 |
